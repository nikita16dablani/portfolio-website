# Portfolio Website

A responsive personal portfolio website developed using HTML, CSS, and JavaScript.

## Live Website

https://nikita16dablani.github.io/portfolio-website/

---

## Project Overview

This project is a personal portfolio website created to showcase professional experience, technical skills, and projects in a clean and responsive format.

The website is built using only frontend technologies and deployed using GitHub Pages.

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages

---

## Project Structure

portfolio-website/
│
├── index.html
├── style.css

---

## File Explanation

### index.html

This is the main structure of the website.

Contains:

- Hero Section
- About Section
- Skills Section
- Experience Section
- Projects Section
- Contact Section

All website content is defined inside this file.

---

### style.css

Responsible for the visual appearance of the website.

Handles:

- Layout
- Colors
- Typography
- Spacing
- Responsive Design
- Cards and Sections Styling

---

### script.js

Contains JavaScript functionality.

Currently used for:

- Future interactive features
- Dynamic effects
- Event handling

The current portfolio requires minimal JavaScript.

---

## Website Sections

### Hero Section

Displays:

- Name
- Professional Title
- Introduction
- Social Links

Purpose:
Provide a quick overview of the portfolio owner.

---

### About Section

Contains a professional summary and background information.

Purpose:
Introduce experience and career focus.

---

### Skills Section

Displays technical skills and technologies.

Purpose:
Showcase technical expertise.

---

### Experience Section

Highlights professional work experience.

Purpose:
Demonstrate industry experience and responsibilities.

---

### Projects Section

Displays major projects and achievements.

Purpose:
Show practical implementation of technical skills.

---

### Contact Section

Provides contact information and professional networking links.

Purpose:
Allow recruiters and professionals to connect easily.

---

## Deployment

The website is hosted using GitHub Pages.

Deployment Steps:

1. Create GitHub Repository
2. Push Source Code
3. Enable GitHub Pages
4. Select Main Branch
5. Publish Website
